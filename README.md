# Portfolio Experimental | León Feldman Reinoso

Este repositorio contiene el código fuente para el portfolio web y "laboratorio visual" de **León Feldman Reinoso**, fotógrafo y director visual radicado en Buenos Aires, Argentina.

## Sobre el Proyecto

El sitio web está diseñado como una galería fotográfica inmersiva y moderna. Presenta un diseño dinámico ofreciendo dos vistas principales para la exploración de las obras:
- **Modo Hoja de Contactos (35mm):** Una cuadrícula inspirada en las tiras de prueba analógicas de laboratorio.
- **Modo Editorial:** Una vista de galería más inmersiva, enfocada en los detalles y la atmósfera de cada imagen.

Además, la interfaz cuenta con un botón de **"Modo Cuarto Oscuro"** que transforma la paleta de colores emulando la iluminación roja de seguridad de un laboratorio fotográfico analógico.

## Características Principales
- **Diseño web moderno:** Uso de *Vanilla CSS*, animaciones fluidas, y efectos translúcidos (*glassmorphism*).
- **Interactividad nativa:** *Vanilla JavaScript* para la lógica de la galería, filtros por categoría (Retrato, Moda, Paisaje, Urbana, Producto), y visor ampliado de fotos (Lightbox).
- **Diseño Responsive:** Totalmente adaptable para dispositivos móviles, tablets y escritorio.
- **Dirección de Arte Premium:** Tipografías combinadas (editoriales y monospace) y paletas de colores sobrias para resaltar el contraste y la textura del trabajo fotográfico.
